## 📌 ¿Qué es Marvel RC?

**Marvel RC** es una plataforma web interactiva diseñada para explorar, comprender y seguir el orden cronológico y de estreno de todas las producciones del universo cinematográfico de Marvel, abarcando desde la **Línea Sagrada del UCM (Tierra-616)** hasta los universos adyacentes de **Mutantes de Fox (X-Men)**, **Spider-Verse (Sony)** y **Los 4 Fantásticos**.

---

## ✨ Características Principales

| Función | Descripción |
| :--- | :--- |
| ⏳ **Doble Orden de Visualización** | Alterna en un clic entre **Orden Cronológico en el Universo** y **Orden de Estreno en Cines**. |
| 🌌 **Filtrado por Universos Paralelos** | Explora por carriles dedicados: Tierra-616 (UCM Principal), Fox Universe (X-Men/Deadpool), Spider-Verse y Los 4 Fantásticos. |
| 🎯 **Ruta Rápida para Doomsday & Secret Wars** | Lista filtrada e imprescindible de películas y series que conectan directamente con el regreso de Robert Downey Jr. como *Victor Von Doom*. |
| 🌳 **Árbol Visual de Líneas Temporales** | Grafo interactivo que muestra bifurcaciones temporales, incursiones y variantes del multiverso. |
| ✅ **Seguimiento Personalizado** | Marca producciones como *Vistas* o agrégalas a tu *Lista de Seguimiento*, con persistencia en tu navegador (`localStorage`). |
| 🔍 **Buscador Instantáneo** | Filtra en tiempo real por título, personajes clave, eventos multiversales o sinopsis. |

## 🚀 Inicio y Desarrollo Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/RocamanMC/marvel-rc.git
cd marvel-rc

# 2. Instalar dependencias
npm install

# 3. Iniciar entorno de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```

## 🛠️ Tecnologías

- **Framework**: [React 18](https://react.dev/) + [Vite 6](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía**: [Lucide React](https://lucide.dev/)
- **Seguridad**: Hash SHA-256 nativo mediante Web Crypto API (`crypto.subtle`)
